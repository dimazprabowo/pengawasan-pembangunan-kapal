# Project notes

## Development environment & file processing
- Pengembangan saat ini memakai server lokal, tanpa Docker dan tanpa Chrome DevTools. Docker/CI di bawah untuk deployment; jangan rebuild/recreate container untuk perubahan development lokal.
- `FileStorageService` khusus disk `local`: `storeTemp()` mengembalikan path; `storeProcessed()`/`copyFromTemp()` mengembalikan array path/name/size dengan UUID. Ekstensi final ditentukan server. `copyFromTemp()` mempertahankan temp sampai metadata berhasil disimpan.
- Empat Job upload (lampiran harian, NC, scan Form NC, eksternal) menggunakan service tersebut. Transaksi metadata gagal harus membersihkan hasil percobaan baru, bukan file lama/temp retry; cleanup temp final di `failed()`. Record completed tidak diproses ulang. Scan bertanda tangan dipertahankan byte-per-byte. Rendering PDF tetap di `PdfPageService`; generator/upload template Word tidak dirombak.
- Verifikasi cepat: `php artisan test --filter="FileStorageServiceTest|FileProcessingJobsTest|NcAttachmentProcessingTest|LaporanExternalAttachmentTest"` (SQLite/fake local storage, tanpa seeder 400 laporan).

## Lampiran Word — margin halaman
- `reportPageImages()` menyimpan WebP sumber dalam manifest `pages.json` dan mengembalikan turunan JPEG siap-sisip di subdirektori `word-ready/` milik cache DOCX yang sama. Kunci mencakup SHA-256 isi sumber, ukuran, kualitas, dan `READY_IMAGE_VERSION`; sidecar `.sha256` memvalidasi hasil sebelum reuse. JPEG dipublikasikan lewat file sementara + rename pada disk lokal. `insertImages()` tidak meng-encode ulang atau menghapus turunan siap-sisip sebagai temp; cleanup lewat `forgetPageImages()`/`deleteDocFile()` tetap menghapus seluruh direktori. Foto/upload asli tetap mengikuti alur lama. Saat algoritma persiapan gambar berubah, naikkan versi cache.
- `WordAttachmentService` mengisolasi halaman eksternal, laporan anak, dan lampiran NC dalam section margin nol dengan referensi header/footer kosong (default/first/even); pembatas memakai margin normal tetapi header/footer kosong, sedangkan konten lanjutan kembali ke section normal. Batas section ditempel pada paragraf terakhir bila memungkinkan; pemisah tidak menambah page break eksplisit di samping section break. Test render PDF memverifikasi jumlah halaman dan tidak adanya footer induk pada pemisah. Halaman sumber diskalakan proporsional tanpa crop otomatis. Seluruh caption tambahan generator (judul, nama file, nomor halaman) tidak dicetak pada halaman isi lampiran; header/footer yang sudah menyatu dengan halaman sumber tetap utuh.
- Footer induk wajib tetap ada pada isi utama sampai daftar LAMPIRAN. Jangan menempelkan `sectPr` pada paragraf placeholder `${...}` yang akan diganti proses berikutnya: batas section ikut terhapus dan footer utama menjadi kosong. Saat penyisipan berurutan, buang paragraf section transisi kosong yang digantikan batas lampiran agar tidak menghasilkan halaman berisi footer saja. Regresi render gabungan NC → harian → eksternal memverifikasi 8 halaman, footer utama pada isi/daftar, serta pemisah/lampiran tanpa footer induk.
- Generator mingguan menambahkan NC sebelum menyisipkan halaman harian; urutan tampil tidak berubah. Regresi: `php artisan test --filter="LaporanExternalAttachmentTest|NcAttachmentProcessingTest"`.

## Docker & CI/CD
- `Dockerfile` multi-stage: `base` (php:8.5-fpm + nginx + supervisor + poppler-utils) → `vendor` → `assets` (node:22, VITE_* di-bake via build-arg) → `test` (`php artisan test` saat build) → `production`. Satu image dipakai service `app`/`worker`/`reverb`/`scheduler` di `docker-compose.yml`; DB PostgreSQL eksternal; `docker-compose.local.yml` menambah postgres untuk dev.
- `entrypoint` menjalankan `config:cache` + `view:cache` sebagai www-data; `route:cache` SENGAJA tidak dipakai (routes/web.php berisi closure). Migrasi via `MIGRATE_ON_START=true` (hanya di service `app`).
- `.dockerignore` wajib mengecualikan `storage/app/tools` (164MB Poppler portable Windows — Linux pakai `poppler-utils`), `storage/app/{private,public,temp,tmp-files}`, `.env*`, `vendor`, `node_modules`, `public/build` — dengan exception `!/storage/app/private/templates` agar template docx default ikut image. Volume `storage_app` di-seed dari image sehingga template docx di `storage/app/private/templates` tetap ada.
- Semua artefak file (lampiran, doc/pdf laporan, template) tersimpan pada **disk default `FILESYSTEM_DISK`** (local maupun s3) — JANGAN hardcode `disk('local')` atau `storage_path('app/...')` untuk file tersimpan; root disk `local` = `storage/app/private`. Tool native (PhpWord, ZipArchive, Word COM, pdftoppm, Intervention) butuh path lokal: pakai `App\Services\FilePathService` (`localPath()` untuk baca, `tempPath()` + `commitLocalFile()` untuk tulis, `exists()/delete()/download()` untuk operasi disk). S3 butuh `league/flysystem-aws-s3-v3` (sudah terinstall).
- `.gitlab-ci.yml`: test → build&push registry → deploy SSH (manual di main). Variabel CI/CD: `DEPLOY_HOST/USER/SSH_KEY/DIR` + `VITE_REVERB_*` (lihat DEPLOYMENT.md).

- Footer harian disisipkan pasca-save oleh `LaporanHarianWordService::ensureFooter()` (bukan di template) agar berlaku untuk template default maupun custom: dua paragraf kanan 8pt `7F7F7F` — "Laporan Harian {nama kapal} — {tanggal}" + "Halaman {PAGE} dari {NUMPAGES}". Pemisah mapping mengikuti regional Word: Word lokal membutuhkan titik koma; koma terbukti menghasilkan "No table of contents entries found" saat diuji via Word COM. `updateFields=true` + field `dirty=true`; verifikasi rendering dengan Microsoft Word, bukan validitas XML saja. Jangan simpan ulang template melalui Word karena placeholder dan cache TOC belum berisi data laporan.
- **Release PDF**: tombol Release di Show men-dispatch `ReleaseLaporanBulananPdfJob` → `DocxToPdfService::convert()` docx→pdf ke `laporan/pdf/` (kolom `pdf_path/pdf_name/pdf_status/pdf_generated_at/pdf_error`, mirror `doc_*`). Driver utama = MS Word COM (`com_dotnet` wajib `extension=com_dotnet` di php.ini; update field TOC sebelum SaveAs wdFormatPDF); fallback LibreOffice `soffice` (env `SOFFICE_BINARY`, terinstal di image Docker). Lampiran kini gambar halaman sehingga ter-render oleh kedua driver. ## NC — Foto & Form NC (Non Conformance Report)
- Lampiran NC sekarang 1:N (`laporan_nc_foto.laporan_nc_id` tidak unique): `NcFileKategori` Open/Close; gambar/PDF. Nama internal model/route `LaporanNcFoto` tetap dipakai. Form harian menambah Open via `syncNc`; List NC menambah Open/Close via `addFiles`. State upload per slot `{row_key}_{uuid}`; file baru tidak menggantikan lampiran lama. Tambah/hapus file tidak dibatasi status NC dan tidak menutup NC; tetap authorize update + scope kapal. Preview/thumbnail di Edit & Show lewat `HasNcFotoPreview`.
- `ProcessNcFoto` menyimpan gambar sebagai WebP q85, PDF asli + `rendered_pages` WebP (urutan halaman). `PdfPageService` memakai Poppler `pdfinfo`/`pdftoppm` (argument array, bukan shell): konfigurasi `PDFINFO_BINARY`/`PDFTOPPM_BINARY`; default nama executable dari PATH. Windows lokal memakai portable di `storage/app/tools/poppler` (gitignored); Linux perlu paket `poppler-utils`. Batas resource: 200 halaman, rendering 45 detik, timeout Job 60 detik. File gagal tidak boleh diabaikan saat generate Word.
- `NcAttachmentWordService` memasukkan halaman PDF sebagai gambar halaman penuh ke DOCX (bukan OCR/altChunk PDF); foto melalui format lampiran. Source/cached image WebP memakai helper `WordImageService` untuk encoding dokumen. Perubahan NC/file NC mengosongkan dokumen terkait via `LaporanNcService::invalidateDocuments` (tidak ada signature ZIP comment).
- Verifikasi tambahan: `php artisan test --filter="NcAttachmentProcessingTest|LaporanNcTest|LaporanNcFormTest|LampiranFileRouteTest|LaporanMingguanWordServiceTest|LaporanBulananTest"`. Test renderer nyata akan skip jika executable Poppler tidak terkonfigurasi.
- Form NC (`laporan_nc_form` + pivot `laporan_nc_form_item`, `LaporanNcFormService`): **Form Temuan** per laporan harian (draft disegarkan tiap generate ulang, hanya NC yang belum masuk form temuan bertanda tangan) & **Form Penutupan** lintas hari (NC Open yang belum ada di draft penutupan lain). Nomor `{kode kapal}-NCR-xxx` per kapal. Status diturunkan dari `file_status` (`NcFormStatus`), `signed_at` null = draft.
- Generate Word NCR - CLOSE hanya memakai lampiran Close (foto dan semua halaman PDF), tanpa fallback Open jika Close kosong. Filter tunggal di `LaporanNcWordService` diterapkan ke salinan relasi untuk kedua jalur lampiran; relasi sumber dan export mingguan/bulanan tidak diubah.
- NC **hanya ditutup** lewat upload scan TTD Form Penutupan (`uploadSigned`, satu transaksi). Reopen di List NC (`LaporanNcService::reopen`). Draft bisa dihapus, form bertanda tangan tidak.
- Halaman NC `LaporanNcList` = SATU index (tidak ada tabel Form NC terpisah): aksi Form Temuan (unduh docx, upload/ganti scan, hapus draft, preview) tampil sebagai chip+ikon di baris header grup tanggal di samping tombol Generate; aksi Form Penutupan sebagai ikon kecil di sel kolom Form Close per baris NC. Pengecualian: chip penutupan yang dicoret (NC di-reopen) hanya histori tanpa aksi. Polling `hasProcessing` memakai relasi `forms` yang sudah eager di `getFiltered`.
- Gate::before super admin mem-bypass cek state di `LaporanNcFormPolicy::delete` — Blade & component tetap cek `isDraft()` eksplisit.
- Dokumen Word digenerate on-the-fly (`LaporanNcWordService`, file temp + `deleteFileAfterSend`). Template default dibangun `php build_laporan_nc_template.php` dari master `storage/app/private/templates/laporan-nc/master-nc.docx` (salinan NC.docx). Placeholder: `${nama_proyek}`, `${judul_form}`, `${nomor_ncr}`, baris `${nc_no}` (diisi nomor NC, mis. NC-001 — kolom "No" di semua tabel NC Word: form, mingguan `tabel_nc`, bulanan `nc_no`) `${nc_masalah}` `${nc_tanggal}` `${nc_pic}` `${nc_status}` `${nc_selesai}` `${nc_tindakan}`, blok `${blok_lampiran}`…`${/blok_lampiran}` dengan baris `${foto_no}` `${foto_gambar}` `${foto_keterangan}`. ## PhpWord TemplateProcessor gotchas
- `findRowStart()` mencari `<w:tr ` (dengan spasi) lebih dulu: baris tabel yang ditulis manual sebagai `<w:tr>` membuat `cloneRow`/`deleteRow` memotong dari baris tabel lain. Selalu beri atribut, mis. `<w:tr w:rsidR="00C0FFEE">`.
- Aktifkan `Settings::setOutputEscapingEnabled(true)` sebelum `setValue`; teks seperti "Engineering & Design" merusak XML dokumen bila tidak di-escape.
- JANGAN pakai auto-numbering Word (`w:numPr`) untuk judul yang teksnya sudah memuat huruf/nomor literal — hasilnya ganda ("A. A. ..."). Tulis nomor literal di teks, lepas `numPr`/`ListParagraph`/`w:ind` dari paragraf judul.
- Tabel ber-lebar `dxa` tanpa `tblLayout fixed` bisa menyusut mengikuti isi sel (autofit) — tampak lebih pendek dari tabel lain yang `pct`. Selaraskan semua tabel konten ke `tblW 5000/pct` + `tcW` persen (gridCol tetap dxa).
- `LaporanHarianWordService::generate()`/`LaporanMingguanWordService::generate()` hanya menulis file — `doc_path` di-update oleh `GenerateLaporan*Job`. Jangan panggil service langsung untuk regenerate; pakai `GenerateLaporanHarianJob::dispatchSync($laporan)` agar file lama terhapus & `doc_path` menunjuk file baru (lampiran mingguan membaca `doc_path`).

## Drawing Register & Blade slots
- Jenis/status adalah katalog global yang dikelola lewat `DrawingCatalog` dan service bersama; revisi menyimpan `drawing_status_id`. Enum `DrawingStatus` hanya mendefinisikan tujuh data awal/label bawaan, bukan validasi pilihan runtime. Hapus katalog terpakai ditolak; riwayat bulanan di-query melalui cutoff, bukan disalin per bulan.
- Beri whitespace/newline setelah penutup named slot sebelum teks literal: penutup slot yang langsung diikuti teks dapat terkompilasi menjadi directive gabungan, merusak output buffer dan root Livewire. Verifikasi dengan `php artisan test --filter=DrawingRegisterTest`.
- `@php(expr)` inline JANGAN berisi closure/arrow `fn`: parser Blade berhenti matching kurung dan mengeluarkan `<?php` tanpa penutup — seluruh sisa view jadi literal dan muncul ParseError `unexpected token "endif"` saat render (lolos `view:cache` karena compile tidak mengeksekusi). Pakai blok `@php ... @endphp` untuk ekspresi apa pun; deteksi dengan `php -l` pada file compiled di `storage/framework/views` bila ragu.

## Dokumen Laporan — Pakai Ulang & Invalidasi
- Sumber tunggal siklus docx: `LaporanDocumentService`. `deleteDocFile()` = hapus docx + cache gambar halaman (dipakai Job generate saat menimpa file lama); `clearDoc()` = kosongkan doc_* + PDF rilis satu laporan (dipakai tombol Hapus Dokumen di Show — TIDAK berantai). Jangan menulis ulang blok hapus doc_path di komponen.
- Perubahan isi WAJIB memanggil invalidasi berantai di SERVICE penulis data (bukan komponen): `invalidateHarian` (harian → mingguan pivot → bulanan bulan_ke-nya), `invalidateMingguan` (mingguan → bulanan), `invalidateMingguanIds` (mingguan yang kehilangan harian lewat `releaseHarianFromOtherMingguan`, kini mengembalikan id), `invalidateNcScope(dataKapal, since)` (NC tampil di rekap semua mingguan sejak dibuat). Titik terpasang: `LaporanHarianService::update/syncAktivitas/deleteLampiran/delete`, `LaporanNcService::syncNc/addFiles/deleteFoto/reopen/deleteForLaporan`, `LaporanNcFormService::uploadSigned` (penutupan), `LaporanMingguanService::create/update/delete/deleteExternal`, `LaporanBulananService::update/delete/deleteExternal`. Fitur baru yang mengubah isi laporan WAJIB ikut memanggilnya.
- Di luar cakupan invalidasi (perlu Generate Ulang manual): perubahan master/data proyek (Data Kapal, Kurva-S, drawing, vendor, material, pengujian, rapat) yang ikut tercetak di dokumen.
- Hapus laporan external lewat `Laporan{Mingguan,Bulanan}Service::deleteExternal($laporan, $id)` (dibatasi relasi induk — jangan `LaporanExternal::find($id)` mentah dari komponen).
- Verifikasi: `php artisan test --filter="LaporanDocumentInvalidationTest|LaporanExternalAttachmentTest|LaporanBulananTest"`.

## Laporan Harian — Dokumen Pendukung

State upload terpisah `laporanExternal.{day}.{index}` agar tidak diserialisasi bersama draft operasional browser. Penghapusan tab hari wajib merapatkan state dokumen bersamaan dengan state hari.

Dokumentasi (kategori/jumlah foto), lalu placeholder isi eksternal dan pemisah dokumentasi sebelum grid foto. Daftar dokumen harian/mingguan menggunakan `WordStyleService::attachmentList`. ## Laporan Harian — Default & Hari Libur
- `LaporanHarianService::previousDayDefaults()` mencari tepat tanggal sebelumnya di proyek yang sama, termasuk draft tab form; hanya rangkaian tanggal yang tercatat `is_libur` boleh dilewati.
